# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| Edge (Latest) | :white_check_mark: |
| < Latest | :x: |

## Reporting a Vulnerability

Please do **NOT** open public GitHub issues for security vulnerabilities.

Follow our [Coordinated Vulnerability Disclosure Policy](README.md) and report directly to:
- **Email**: `security@praebellum.com`
- **Alternative**: `contact@praebellum.com`
- **Encrypted Comms**: Request PGP public key via email before attaching sensitive exploit payloads.

We adhere strictly to coordinated disclosure timelines (90-day standard or mutually agreed remediation window).
